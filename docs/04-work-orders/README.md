# Work orders

Sol's bounded work orders are committed here, one file per order, in the pull
request they govern (`WORKFLOW_HARNESS.md` section 3 step 1). Naming:
`WO-<yyyymmdd>-<slug>.md`. Documentation-only orders may instead be quoted in
full in the PR body. Orders are historical records once merged; a correction is
a new order that references the original, never an edit.
